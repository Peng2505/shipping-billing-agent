# 人工验收截图

本目录为正式交付证据，**允许纳入 GitHub 版本控制**，请勿整体加入 `.gitignore`。

## 子目录

| 目录 | 内容 |
|------|------|
| `PDF1/` | 样例 PDF1 工作台 / 费用 / 账单核对 |
| `PDF2/` | 样例 PDF2 五页走查（工作台 → JSON） |
| `EML/` | 邮件样例文档 / 费用 / 审计 |
| `PNG/` | 图片样例真实 OCR 与核对结果 |
| `Synthetic/` | 合成笔试样例（如 CREATE） |

## 提交前检查

截图中不得出现：

- API Key / 访问令牌
- 完整临时 Tunnel 主机名或签名 URL
- `.env` 明文或其他密钥

服务状态卡片应仅显示「已配置」类文案，不展示密钥值。
